demi mewujudkan majelis fisik di **Gunungguruh, Sukabumi, Jawa Barat** —
tempat ilmu ini terus diajarkan dan dikembangkan untuk masyarakat.

## 📋 Cara Menggunakan

### Sebagai Pembaca Individu
1. Mulai dari [Portal Utama](index.html)
2. Baca secara berurutan dari halaman 01–04
3. Kerjakan worksheet dengan jujur di setiap modul
4. Lanjutkan ke bonus hipnosis dan mental kaya
5. Cetak sertifikat setelah menyelesaikan program
6. Berikan donasi ikhlas jika bermanfaat 🤲

### Sebagai Fasilitator / Trainer
1. Pelajari panduan di [Master Guide](sadar-sejati-master-guide.html)
2. Tampilkan file HTML langsung dari browser saat pelatihan
3. Bagikan worksheet ke peserta sebelum sesi
4. Gunakan sertifikat di akhir program
5. Jadikan halaman donasi sebagai bagian dari closing sesi

### Sebagai Ebook Digital
1. Konversi file HTML ke PDF via browser (Ctrl+P → Save as PDF)
2. Gabungkan semua PDF dengan tools gratis
3. Distribusikan via WhatsApp, Tokopedia, atau Gumroad
